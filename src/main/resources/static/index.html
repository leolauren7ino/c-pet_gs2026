O que o cidadão ganha

  • Um só lugar para reportar, sem precisar procurar canal por canal.
  • Acompanhamento do caso pelo código, sem login.
  • Menos risco sanitário no bairro, com apoio das ações de zoonoses.
  • Dados abertos agregados por região, sem endereço exato nem dados pessoais.
